# State Engine Checks

1. Production cannot unlock before proficiency passes.
2. Every state change requires a source event.
3. Historical events are append-only.
4. Manual override requires Eric authorization.
5. Published requires publication evidence.
6. Stale knowledge requires reassessment before mastery.
7. Canonical state wins over dashboard disagreement.
8. Shared correlation IDs reconstruct one workflow run.
9. A replacement AI provider must reach the same transition decision from the same inputs.
