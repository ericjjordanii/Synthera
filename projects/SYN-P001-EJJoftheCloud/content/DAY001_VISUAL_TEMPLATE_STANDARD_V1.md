# EJJoftheCloud Day 001 Visual Template Standard V1

Status: LOCKED
Project: SYN-P001 EJJoftheCloud
Authority: Eric Jordan
Master reference: Day 001 carousel assets

## Core rule
Every DayXXX carousel must be created by cloning the Day 001 visual system first and replacing only lesson-specific content second.

No approximate redesigns. No new layout experiments. No visual drift.

If any written numerical specification conflicts with the actual approved Day 001 assets, the Day 001 assets are authoritative.

## Immutable production properties
- Canvas: 1122 x 1402 pixels, portrait.
- Six-slide carousel.
- Same EJJ OF THE CLOUD header placement and treatment.
- Same "365 DAYS OF CLOUD" label placement and styling.
- Same footer divider, season label, page-number placement, and visual treatment.
- Same dark navy / near-black field.
- Same azure-blue accent system.
- Same white primary typography.
- Same Inter-style sans-serif typography family and weight hierarchy used by the Day 001 master.
- Same left alignment, margins, spacing rhythm, title scale, paragraph scale, bullet treatment, divider treatment, border treatment, and information density.
- Same technical line-art language, cloud/grid motifs, thin blue strokes, and restrained glow treatment.
- Same six-slide composition roles:
  1. Cover
  2. Definition
  3. Analogy / Simple Explanation
  4. Visual / Comparison
  5. Real-world Example
  6. Key Takeaway / Mission Complete

## Allowed changes
Only lesson-specific content may change:
- day number
- lesson title
- definitions
- analogy wording
- comparison wording
- examples
- takeaways
- next-mission text
- content-specific supporting labels where required

## Prohibited changes
- changing the brand palette
- changing fonts or typographic character
- changing canvas proportions
- moving the header/footer system
- inventing a new card system
- introducing a dashboard layout
- changing the page-number system
- changing the season-footer system
- using a different visual genre
- accepting output that is merely "similar" to Day 001

## Production algorithm
1. Load approved Day 001 slide corresponding to the target slide number.
2. Treat that slide as the master template.
3. Preserve its visual hierarchy and fixed branding structure.
4. Replace only lesson-specific content.
5. Compare the candidate against Day 001 before promotion.
6. If layout, typography, spacing, color, or composition visibly drift, mark ASSET_VALIDATION_FAILED and repair automatically.
7. Do not stop the mission for visual repair unless human judgment is genuinely required.
8. Only validated assets may enter Approved.

## Validation gate
Before Production Complete, Content Studio must explicitly verify:
- TEMPLATE_CLONE_FIRST = PASS
- CANVAS_MATCH = PASS
- HEADER_MATCH = PASS
- FOOTER_MATCH = PASS
- TYPOGRAPHY_HIERARCHY_MATCH = PASS
- COLOR_SYSTEM_MATCH = PASS
- SPACING_RHYTHM_MATCH = PASS
- COMPOSITION_MATCH = PASS
- NO_CROSS_LESSON_CONTENT = PASS
- NO_SUPERSEDED_ASSETS_IN_ACTIVE_PACKAGE = PASS

Failure of any required check blocks promotion and triggers automatic repair.

## Permanent instruction
Same format. Same colors. Same fonts. Same styles. Same branding. New lesson only.
